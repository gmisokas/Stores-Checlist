# Lartecono Stores Checklist

Απλή εφαρμογή για κινητό με τα checklist **Ανοίγματος** και **Κλεισίματος** καταστήματος.
Εκτυπώνεται και σε A4.

## Για τους υπαλλήλους
1. Ανοίγουν τον σύνδεσμο της εφαρμογής στο κινητό.
2. Συμπληρώνουν **Ημερομηνία**, **Υπεύθυνο**, **Κατάστημα** και διαλέγουν **Άνοιγμα** ή **Κλείσιμο**.
3. Σε κάθε γραμμή πατάνε **✓** (έγινε) ή **✗** (δεν έγινε). Με το «Σημείωση» γράφουν παρατήρηση.
4. Στο τέλος πατάνε **«Αποστολή στο Viber»** και διαλέγουν την ομάδα/το άτομο.

- Οι **κίτρινες** γραμμές είναι ιδιαιτερότητες του συγκεκριμένου καταστήματος.
- Οι **κόκκινες** γραμμές είναι πολύ σημαντικές.
- Η πρόοδος σώζεται στο κινητό: αν κλείσει η σελίδα, δεν χάνεται τίποτα.
- Στο «Κατάστημα» υπάρχει και η επιλογή **ΓΕΝΙΚΟ**, για το γενικό checklist χωρίς ιδιαιτερότητες.
- Με το **«Αποθήκευση σε Excel»** κατεβαίνει αρχείο .xlsx με την ενότητα που βλέπεις και ό,τι έχει συμπληρωθεί.

### Καθαριότητες / Αποψύξεις (αρχείο)
- Τρίτο κουμπί δίπλα στο Άνοιγμα/Κλείσιμο. Διαλέγουν **Γενική καθαριότητα** ή **Απόψυξη**, μετά εξοπλισμό/χώρο, **Νο** (για καταψύξεις, ψυγεία, βιτρίνες) και πατάνε **✓**.
- **Πρώτη χρήση**: εμφανίζεται «Προσοχή!» και ο/η **υπεύθυνος καταστήματος** δηλώνει πόσα μηχανήματα έχει το κατάστημα (Νο 1, Νο 2…) και ποιοι χώροι υπάρχουν. Αλλάζει από το «Εξοπλισμός καταστήματος».
- **Προτεινόμενα για σήμερα**: η εφαρμογή μοιράζει τις εργασίες στον μήνα. Οι γενικές καθαριότητες μόνο Δευτέρα–Παρασκευή, οι αποψύξεις όλες τις ημέρες. Το πλήρες πρόγραμμα φαίνεται στο «Πρόγραμμα μήνα» (ημερολόγιο).
- **Έλεγχος**: οι εβδομαδιαίες μετράνε ανά εβδομάδα (1–7, 8–14, 15–21, 22–τέλος μήνα), οι μηνιαίες για όλο τον μήνα. Στο «2–3 φορές» μετράει το ελάχιστο.
- **Από τις 25 του μήνα**: υπενθύμιση για ό,τι εκκρεμεί. **Από την 1η του επόμενου μήνα**: ειδοποίηση με ό,τι δεν έγινε και κουμπί «Αποστολή στο Viber».
- **Αποθήκευση σε Excel**: πριν την εξαγωγή διαλέγεις μήνα και πόσα από κάθε μηχάνημα θα μπουν. Βγαίνουν 3 φύλλα: Γενική καθαριότητα, Απόψυξη (ημέρες του μήνα, προτεινόμενες ημέρες, ✓ όσα έγιναν) και Καταχωρήσεις (ποιος, πότε).
- **🔒 Αρχείο (με κωδικό)**: σύνοψη ανά μήνα, όλες οι καταχωρήσεις, διαγραφή λαθών.
- Ο εξοπλισμός και οι καταχωρήσεις σώζονται **στη συσκευή** όπου γίνονται. Καλύτερα σε κάθε κατάστημα οι καταχωρήσεις να γίνονται από την ίδια συσκευή.

- Την πρώτη φορά εμφανίζεται παράθυρο με οδηγίες για να μπει η εφαρμογή στην αρχική οθόνη (iPhone ή Android). Με το τικ «Να μην εμφανιστεί ξανά» δεν ξαναεμφανίζεται. Οι οδηγίες ξανανοίγουν από το «Οδηγίες εγκατάστασης» κάτω-κάτω.

## Για τον area manager: αλλαγές χωρίς κώδικα
Κάτω-κάτω στη σελίδα υπάρχει ο σύνδεσμος **«Διαχείριση»**:
- **Γενικό checklist**: προσθήκη, αλλαγή, διαγραφή, μετακίνηση γραμμών, σήμανση «Κόκκινα έντονα».
- **Καταστήματα**: νέο κατάστημα, μετονομασία, διαγραφή, και έξτρα γραμμές (ιδιαιτερότητες) σε όποια θέση θέλεις.
- **Καθαριότητες**: κωδικός του «Αρχείου» και λίστα εξοπλισμού/χώρων με τις συχνότητες γενικής καθαριότητας και απόψυξης (φορές ανά εβδομάδα ή μήνα, «Αριθμημένο» για Νο 1–10).
- **Αποθήκευση**: «Αποθήκευση για όλους» → οι αλλαγές ανεβαίνουν και σε 1–2 λεπτά τις βλέπουν όλα τα κινητά.

> Μη γράφεις ποτέ ποσά παγίου ή κωδικούς συναγερμού/POS.

### Ρύθμιση κλειδιού (μία φορά, μόνο στο δικό σου κινητό)
Για να δουλέψει η «Αποθήκευση για όλους» χρειάζεται ένα κλειδί (token) από το GitHub:
1. GitHub → φωτογραφία προφίλ → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. **Repository access**: «Only select repositories» → διάλεξε αυτό το repo.
3. **Permissions → Repository permissions → Contents**: «Read and write».
4. Δημιούργησε το token, αντίγραψέ το και επικόλλησέ το στην εφαρμογή: Διαχείριση → Αποθήκευση → «Κλειδί GitHub».

Το κλειδί μένει μόνο στη συσκευή σου. Μην το δίνεις σε υπαλλήλους.
Χωρίς κλειδί, υπάρχει το κουμπί «Λήψη αρχείου data.json»: το ανεβάζεις χειροκίνητα στο GitHub (Add file → Upload files).

## Δημοσίευση (GitHub Pages)
1. Τα αρχεία πρέπει να βρίσκονται στον κλάδο `main`.
2. GitHub → repo → **Settings** → **Pages** → Source: «Deploy from a branch» → Branch: `main` / `(root)` → Save.
3. Σε 1–2 λεπτά η εφαρμογή είναι στο `https://<λογαριασμός>.github.io/<repo>/`.

Σημείωση: σε **ιδιωτικό** repo το GitHub Pages χρειάζεται πληρωμένο λογαριασμό. Σε δωρεάν λογαριασμό το repo πρέπει να είναι δημόσιο (το checklist δεν περιέχει ευαίσθητα στοιχεία).

## Αρχεία
- `index.html`, `style.css`, `app.js` – η εφαρμογή.
- `cleaning.js` – το αρχείο καθαριοτήτων/αποψύξεων (πρόγραμμα, έλεγχος, Excel).
- `manifest.webmanifest`, `assets/` – όνομα, λογότυπο και εικονίδια για την αρχική οθόνη.
- `data.json` – οι γραμμές του checklist και τα καταστήματα (αλλάζει από τη Διαχείριση).
